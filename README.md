# oidc-check

Throwaway test repository of the Platanor HSM project (GH-01…GH-04, GH-07, GH-08 in the
verification plan): GitHub Actions OIDC tokens as signed build receipts. Contains no firmware.

Tokens are never printed in full: the log shows the header and claims only, and the full
tokens are uploaded encrypted to a key held offline. This repository will be deleted.
